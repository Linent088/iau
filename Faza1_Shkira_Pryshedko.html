1.3 Hypotézy a štatistické testy¶

A. Dve hypotézy¶

Prvá hypotéza: bearingTemp je pri poruche vyšší. Jej H0: priemerný rozdiel nie je kladný.

Druhá hypotéza: Flowmeter je pri poruche nižší. Jej H0: priemerný rozdiel nie je záporný.

Párovými t-testmi porovnáme priemery oboch stavov v rovnakej jednotke. Vyberieme známe jednotky uvedené najneskôr v roku 2023. Predpokladáme nezávislosť jednotiek. Hladina významnosti každého testu je 0,025. Hodnotu 0,05 delíme medzi dva testy.

platne_id = units.loc[units["commission_year"] <= 2023, "id_unit"]
test_data = readings[readings["id_unit"].isin(platne_id)]
priemery_stavov = test_data.groupby(["id_unit", "failure"])[["bearingTemp", "Flowmeter"]].mean()

teplota = priemery_stavov["bearingTemp"].unstack().dropna()
prietok = priemery_stavov["Flowmeter"].unstack().dropna()
rozdiel_teploty = teplota[1] - teplota[0]
rozdiel_prietoku = prietok[1] - prietok[0]

test1 = stats.ttest_rel(teplota[1], teplota[0], alternative="greater")
test2 = stats.ttest_rel(prietok[1], prietok[0], alternative="less")

B. Štatistická sila¶

Overíme silu pri 1022 pároch. Použijeme scenáre d = 0,05, d = 0,1 a d = 0,2. d je priemerný rozdiel delený smerodajnou odchýlkou párových rozdielov. Ide o orientačné efekty v smere alternatívy. Za dostatočnú považujeme silu aspoň 80 %.

n = min(len(teplota), len(prietok))
hranica = stats.t.ppf(0.975, n - 1)
for efekt in [0.05, 0.1, 0.2]:
    posun = efekt * np.sqrt(n)
    sila = stats.nct.sf(hranica, n - 1, posun)
    print("Efekt d =", efekt, "- sila:", round(100 * sila, 5), "%")

Prakticky významná veľkosť efektu nie je určená. Ide o analýzu citlivosti. Nie je to záruka pre každú zmenu.
